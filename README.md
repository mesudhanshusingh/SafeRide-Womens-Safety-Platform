# SafeRide

SafeRide is a women safety web application made to provide a safer experience while travelling.

It includes features like ride tracking, SOS alerts, driver verification, safety routes, trusted contacts and an AI-based safety assistant.

## Features

- User Login & Registration
- Live Ride Tracking
- SOS Emergency Alert
- Driver Verification
- Safe Route Suggestions
- AI Safety Risk Analysis
- Trusted Contacts
- Community Safety Alerts
- Complaint Reporting
- Admin Dashboard

## Tech Stack

- HTML, CSS, JavaScript
- Bootstrap
- Java Spring Boot
- Python FastAPI
- MySQL
- MongoDB
- Leaflet.js
- JWT
